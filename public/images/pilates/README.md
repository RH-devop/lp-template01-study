# public/images/pilates/ 画像配置ガイド

オンラインピラティスLP用の画像フォルダです。実写真は未配置のため、
現在 `lib/content.ts` 側の画像 `src` は暫定的に `/placeholder.svg` を参照しています。
実際の写真を配置したら、`lib/content.ts` 内のコメント（`差し替え予定: /images/pilates/...`）
に従って `src` を差し替えてください。

## フォルダの用途

| フォルダ | 用途 |
|---|---|
| `hero/` | Hero右側の写真（本人がピラティスをしている写真など） |
| `profile/` | Profile（About）セクション用の本人写真 |
| `lesson/` | オンラインレッスン・指導風景の写真 |
| `learning/` | 講習・研修など学びの様子の写真 |
| `lifestyle/` | 自然な普段の様子（食事・生活等はブランド世界観の補助として最小限に） |
| `gallery/` | Moments（Gallery）セクション用の写真 |
| `og/` | OGP/SNSシェア用画像（1200×630目安） |

## 選定時の注意（AGENTS.md / CLAUDE.md より）

- このLPは、本人が指導しているスタジオのLPではありません。スタジオ写真を使う場合も
  「このスタジオで今回のオンラインサービスを提供している」と誤認される見せ方は避けてください。
- 主役は「どこで受けるか」ではなく「誰から教わるか」です。設備・大人数レッスンの写真は
  メインに据えないでください。
